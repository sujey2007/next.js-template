# Changelog

All notable changes to this project template should be documented here.

## [1.0.0] - 2026-09-10

### Added
- Next.js application using the App Router.
- Turborepo monorepo structure with pnpm workspaces.
- Shared UI component package.
- Shared utility package.
- Shared ESLint and TypeScript configuration packages.
- Tailwind CSS 4 styling setup and reusable design tokens.
- Responsive landing-page reference implementation.
- Website asset extraction script for colors, fonts, stylesheets, and images.
- Environment variable example file.
- GitHub Actions CI workflow.
- Repository guidance for coding agents and AI assistants.

### Notes
- The template is intended to be copied or cloned and customized for individual projects.
- Update this changelog when the reusable foundation, developer workflow, or repository conventions change.
